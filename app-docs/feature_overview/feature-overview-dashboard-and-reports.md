## Overview

Use the Dashboard in DRX to see today’s sales totals and transaction counts at a glance, track trends over time, and identify best‑selling items. From the same area, you can open simple reports and filter them by store to compare locations or focus on one. This page walks you through viewing the Dashboard, applying store filters, and exporting or sharing what you see.

## When to use it

- Check today’s sales and the number of transactions in real time
- Review sales trends over recent days or weeks
- Identify best‑selling items and categories
- Run simple reports and filter results by store or location
- Share or save a snapshot of performance for your team

## How to use it

1. **Open** DRX and go to the area that shows your Dashboard. You’ll see today’s sales, transaction counts, and summary cards for trends and best sellers.
2. **Review** Today’s sales and transactions. Confirm the date shown reflects the current business day.
3. **Scan** the trends section to see changes over time. Look for visual indicators that compare today to recent periods.
4. **Check** the best sellers list to see top‑performing items. Use this to guide restocking or promotions.
5. **Filter** by store if you operate multiple locations. Apply the store filter to focus the Dashboard and reports on a single store or compare locations one at a time.
6. **Open** reports from the Dashboard area to view simple, ready‑made summaries (for example, sales by day or item). The store filter you set carries into these reports when available.
7. **Adjust** the date range in a report if you need a broader or narrower view (such as today, this week, or a custom range) when that control is present.
8. **Export or share** the report using the available action in the report view when you need to save a copy or send results to your team.

## Options and settings

- Store filter: Limits Dashboard and report data to a specific store or location.
- Date range: Changes the period shown in a report to focus on today or a selected time window.
- Best sellers view: Shows top items based on sales for the current filter and time period.

## Tips

- Set your store filter before opening a report so the results match the location you care about.
- If a report looks empty, confirm the selected store and date range include days you were open.
- Use best sellers alongside inventory to decide what to reorder soon.
- Revisit trends after promotions or events to see how performance changed.
