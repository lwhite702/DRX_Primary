## Overview

DRX helps you serve customers while collecting the least amount of personal data. You can create customer records with an alias, leave contact fields optional, mask sensitive details when viewing them, and remove stored data on a schedule you control. This page explains how to set up a low‑data customer profile, take a sale using that profile, and manage what is shown, shared, and retained.

## When to use it

- You want to track purchases without storing full names or contact details.
- You need to look up customers by a nickname or receipt ID instead of personal info.
- You must hide sensitive details from staff who don’t need to see them at the register.
- You follow policies that require deleting or minimizing stored customer data.

## How to use it

1. **Add a customer with minimal data.** Open your customer list and create a new customer. Enter an alias (for example, a nickname or company name). Leave personal fields you don’t need blank.
2. **Use optional contact fields only when needed.** If you need to send a receipt or order update, add just one contact method. Otherwise, skip contact fields.
3. **Mask sensitive details during daily use.** When viewing a customer, use the on‑screen control that hides full contact details so only the last few characters show. Unmask temporarily only if you have a clear need, then return to masked view.
4. **Ring up a sale with an alias.** Start a sale, attach the customer by searching their alias, and complete checkout as usual. If the customer prefers not to share contact info, choose a receipt option that does not store new details.
5. **Update or remove data later.** If a customer asks you to minimize stored data, edit their profile and delete unneeded fields, keeping only the alias or an internal note that is not personal.
6. **Set a retention window.** In your account or location settings, choose how long to keep customer contact data. Confirm the schedule so old data is removed automatically according to your policy.
7. **Review what staff can see.** Check your team access settings to ensure only the right roles can view unmasked details. Adjust access if a role should see masked data only.

## Options and settings

- Aliases: Create and search customer records using a non‑identifying name.
- Optional fields: Leave email, phone, and address blank unless needed for a transaction.
- Masked view: Hide full contact values on screen; reveal temporarily when necessary.
- Retention controls: Choose how long customer contact data is stored before it is removed.
- Team access: Limit which roles can view or unmask sensitive customer details.

## Tips

- Collect only what you need for the current transaction; you can always add more later with consent.
- Use receipt numbers or aliases to find past purchases without storing personal information.
- If a field is not required on screen, leaving it blank is the most privacy‑preserving choice.
- Before deleting data, confirm you have the records you need for taxes or returns based on non‑personal identifiers.
