# Marketing Content Agent Workflow

Use this workflow for every DRX marketing copy update.

1. Read `docs/MARKETING_TRUE_FEATURE_LIST.md`.
2. Validate every claim against `docs/MARKETING_FEATURE_CLAIM_MATRIX.md`.
3. Update marketing pages via `apps/marketing/lib/feature-canon.ts`.
4. Keep wording aligned with the canonical DRX voice and section structure.
5. Do not promote any `Beta` or `Planned` claim to `Live` without matrix + evidence updates.
6. For DRX Privacy ProteXion content, use non-jargon operator language and source every claim from the canonical list + matrix.
