## Collect less and protect the rest

Deelrx CRM supports customer tracking without requiring a real name or contact details. Use the privacy mode that matches the business and keep optional fields empty when they are not needed.

## Privacy modes

- **Alias Mode:** uses a nickname or other alias with minimal customer information.
- **Standard Mode:** allows light customer tracking with optional contact details.
- **Business CRM Mode:** supports fuller customer records when the business chooses to collect them.

Admins can review the current mode in Settings. Changing the mode does not erase existing data by itself.

## Safe customer handling

- Explain why information is requested.
- Add optional fields only when the customer agrees.
- Allow checkout without a customer profile.
- Use masking on shared screens when available.
- Avoid copying personal information into notes, exports, screenshots, or support tickets.
- Give each team member only the access needed for their role.

## Sensitive fields and Vault Mode

DRX encrypts supported sensitive customer fields. Vault Mode keeps unlock keys outside the database. Encryption and masking reduce exposure, but they do not replace good account security, careful access control, or approved device practices.

## Temporary profiles and retention

Supported privacy settings can use temporary profile windows and cleanup controls. An Admin should confirm the active policy before promising when a profile will be removed.

## Data access, correction, or deletion request

1. Send the request through the approved support channel.
2. Record the request without copying unnecessary personal information.
3. Verify the requester's authority using the approved process.
4. Identify the correct workspace and records.
5. Have an authorized Admin review the action.
6. Complete the supported access, correction, retention, or deletion workflow.
7. Record completion without exposing the customer's data.

Do not delete records simply because someone sends an unverified email. Do not promise a legal outcome or deadline that has not been confirmed for the request.

## Account security

- Use your own account.
- Keep sign-in methods and recovery channels current.
- Sign out of shared devices.
- Report unexpected access or workspace membership promptly.
- Never send passwords, session links, card data, encryption keys, or API credentials to support.

## Report a privacy or security concern

Contact support with the workspace, time, affected feature, and a description of what happened. Use references instead of customer data. If there is active unauthorized access, stop using the affected account and notify an Admin immediately.
