# Inventory: Manage Stock Without Guessing

Track what came in, what went out, and what needs action now.

## What this does

Covers the main inventory workflow: overview, intake, and adjustment.

## Who can use it

Manager, Owner (staff access depends on permissions)

## Before you start

- Product records and units should be set.

## Step-by-step

1. Open `Inventory` for current stock view.
2. Use `Inventory > Intake` to add incoming stock.
3. Use `Inventory > Adjust` for corrections (increase/decrease/set).
4. Add a clear reason on adjustments to keep traceability.
5. Re-check affected products in overview.

## What happens next

Inventory updates feed sales availability and reporting accuracy.

## Tips

- Write short but specific adjustment reasons.
- Intake in small, frequent batches instead of giant catch-up edits.

## Common mistakes

- Using manual set-to adjustments when intake is the right move.
- Skipping reason fields.

## Troubleshooting

- If counts drift, compare intake + adjustments + recent sales.
- If an item disappears in POS, verify product status and stock state.
