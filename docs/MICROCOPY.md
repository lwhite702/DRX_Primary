# Deelrx CRM – Microcopy

## Rules

- **Length**: Max 4 words
- **Tone**: Plain, Human, Non-corporate
- **Naming**: Avoid product names. Use **DRX** if needed. Never _DRX CRM_.

## Strings

### Confirmation

- Done.
- Got it.
- Saved.
- Recorded.
- Counted.
- Payment logged.

### Empty States

- Nothing here yet.
- Ready for data.
- Clear board.
- Start a tab.
- No history.

### Status Updates

- Syncing...
- Up to date.
- Working...
- Offline. Saving locally.
- Connecting...

### System Reassurance

- We logged that.
- It’s safe.
- Backed up.
- No leaks.
- Key secured.

### Subtle Branding

- DRX active.
- System quiet.
- Deelrx running.
- Mode: Private.
