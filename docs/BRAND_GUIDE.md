# Deelrx CRM – Brand Guide

## 1. Brand Positioning

Deelrx CRM is an operational tool, not a lifestyle product.

It exists to:

- Reduce errors
- Increase accountability
- Make daily operations smoother
- Keep records trustworthy

The brand should feel stable, not trendy.

---

## 2. Visual Identity Principles

### Design Philosophy

- Function first
- Visual clarity over decoration
- Information density balanced with touch accessibility

---

## 3. Color Usage

- Neutral base colors for most surfaces
- Accent colors reserved for:
  - Primary actions
  - Warnings
  - Status indicators
- Red is reserved for destructive actions only
- Green indicates completion, not celebration

High contrast is mandatory for accessibility.

---

## 4. Typography

- Sans-serif, highly readable fonts
- Consistent sizing scale
- No decorative fonts
- No condensed fonts for numeric data

Numbers must be legible at a glance.

---

## 5. Layout and Interaction

### Mobile First

- POS flows optimized for thumb reach
- Large tap targets
- Minimal modal stacking

### Desktop

- Dense tables allowed
- Keyboard navigation encouraged
- Clear hierarchy over visual flourish

---

## 6. Icons and UI Elements

- Icons must be universally recognizable
- No novelty icons
- Labels accompany icons in critical flows

---

## 7. Data Presentation

- Tables over charts when precision matters
- Charts only when trends are the goal
- Always allow drill-down to raw data

---

## 8. Accessibility

- WCAG AA minimum
- Color is never the only signal
- All actions must be reachable without fine motor precision

---

## 9. Brand Guardrails

The visual system should support the voice in `BRAND_VOICE.md`.

- Keep critical flows direct and calm.
- Use light personality in marketing, tours, and low-risk empty states.
- Do not use jokes for money, access, privacy, security, deletion, or data loss.
- Keep product instructions useful. Do not paste marketing slogans into a task.
- Prefer familiar labels over technical or coined feature names.

This is a working tool. It should feel dependable and human.
