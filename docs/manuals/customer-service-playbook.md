# Customer Service Playbook

You are the calm relay between customer frustration and an active store. Keep it simple, quick, and clear.

## What good support sounds like

- Be fast, clear, and human.
- Confirm what changed before saying it is fixed.
- Add workspace context to every handoff.
- Ask only for data needed to solve the issue.

## Intake script (first)

1. “Tell me what happened, in one sentence.”
2. “Where and when did it happen?”
3. “What did the app show?”
4. “What should have happened instead?”

## Fast triage

### Checkout blocked

1. Check product search and scan status.
2. Confirm discounts, taxes, and tender list.
3. Validate tender permissions and notes.
4. If still blocked, escalate with exact time and workspace.

### Customer not found

1. Ask for alias and approximate receipt time.
2. Confirm whether the sale had customer attached.
3. Verify attachment status in history.
4. If no attach exists, follow store policy for unaffiliated sale handling.

### Receipt failed

1. Confirm sale is complete.
2. Re-send from sale detail.
3. Send digital fallback if needed.
4. If no send path exists, escalate with exact message.

### Credit issue

1. Confirm alias and workspace.
2. Confirm payment path and expected balance.
3. Confirm reference note exists when required.
4. Return corrected status or escalate.

### Inventory mismatch

1. Confirm workspace and product.
2. Compare sales, adjustments, and pending approvals.
3. Escalate if no matching movement exists.

## Escalation packet

Always send:

- Workspace
- Time and timezone
- User role and action
- Expected result
- Actual result
- Screen proof or exact error text

## Response templates to use now

- “Got it, I confirmed the flow and I’m fixing this now.”
- “This is a policy hold. I sent it to an admin and will update you once it moves.”
- “It is fixed. Please retry and confirm on your side.”

## Escalate to admin when

- Access is denied after role review.
- Balance or credit visibility is missing.
- Stock keeps drifting after clean checks.
- Reports do not match after same workspace and date range.
