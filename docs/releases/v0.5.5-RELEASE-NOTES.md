# DRX v0.5.5 Release Notes

**Release Date:** 2026-05-31  
**Status:** Production Ready

---

## Summary

This release completes the final production readiness audit and resolves all launch blockers for the DRX beta rollout. Key improvements include complete decommissioning of the legacy Supabase system, native Next.js AI route migrations, inventory ledger transactional mutations, privacy-native identity management, and complete test suite reliability.

## What's New

### Supabase Decommissioning & Native AI Routes
- Decommissioned legacy Supabase Edge Functions.
- Migrated all AI routing to native Next.js AI route handlers for `inventory-health` and `pricing-inventory`.
- Purged all legacy Supabase Edge files, configuration directories, and local configurations.

### Inventory Ledger Hardening & Mutation Engine
- Introduced a new transactional inventory mutation engine supporting audit-safe ledger updates.
- Implemented unique intake batch mapping to guarantee strict FIFO (First-In, First-Out) integrity across inventory adjustments, sales, returns, shrinkages, and transfers.
- Added detailed architecture documentation at `docs/architecture/inventory-ledger-optimization-plan-2026-05-23.md`.

### Privacy-Native Customer Identity
- Integrated ephemeral customer profile lifecycle gates.
- Added a privacy-native customer cleanup queue route (`/api/privacy/cleanup/queue`) gated by PostHog feature flags.

### Compliance & SDK Adapters (Launch Blockers Resolved)
- **PostHog Analytics**: Migrated from direct `posthog-js` to `@wrelik/analytics/client`.
- **Sentry Error Tracking**: Migrated from direct `@sentry/nextjs` to `@wrelik/errors/*` for both server and client.
- **Mobile Sentry**: Added `@sentry/react-native` via `@wrelik/errors/react-native`.

### Quality & Test Assurance
- Fixed unit test mock discrepancies in `pos-baseline.test.ts` and `validate-credit-route.test.ts`.
- Validated that all **32 test suites and 231 tests** pass cleanly with 100% coverage reliability.
- Integrated unified fail-fast gating under `.github/workflows/ci-gate.yml` with visual regression and accessibility check support.

## Upgrade Path

1. Pull the latest `main` branch.
2. Run `pnpm install` to update workspace packages.
3. Verify local build via `pnpm run build` and test suite execution via `pnpm run test:run`.
4. Deploy the production bundle.
