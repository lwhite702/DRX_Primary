# DRX v0.5.5 Release Notes

**Release Date:** 2026-04-09  
**Status:** Production Ready

---

## Summary

This release completes the production readiness audit and resolves all launch blockers for the DRX beta rollout. All third-party SDK integrations now comply with the `@wrelik-kit` adapter policy.

## What's New

### SDK Compliance (Launch Blockers Resolved)
- **PostHog Analytics**: Migrated from direct `posthog-js` to `@wrelik/analytics/client`
- **Sentry Error Tracking**: Migrated from direct `@sentry/nextjs` to `@wrelik/errors/*`
- **Feature Flags**: Migrated from Supabase to PostHog via `@wrelik/analytics/client`
- **Mobile Sentry**: Added `@sentry/react-native` via `@wrelik/errors/react-native`

### New Features
- **Automatic User Identification**: Users are now automatically identified in PostHog when they authenticate
- **PostHog Feature Flags**: Full feature flag support with `isFeatureEnabled()`, `getFeatureFlag()`, etc.
- **Mobile POS**: Verified complete implementation with cart, checkout, and AI pricing

### Documentation
- `docs/@wrelik-kit-usage.md` - Complete guide for using @wrelik/* packages
- `docs/feature-flags.md` - Feature flag naming conventions and best practices
- `docs/PRODUCTION_LAUNCH_CHECKLIST.md` - Complete launch sequence and rollback plan
- `docs/audits/DRX_PRODUCTION_READINESS_AUDIT_2026-04.md` - Full audit report

## Breaking Changes

None. All changes are backwards compatible.

## Migration Notes

### For Developers
If you have local code using direct PostHog or Sentry imports, update to use the adapters:

```typescript
// Before (banned)
import posthog from "posthog-js";
import * as Sentry from "@sentry/nextjs";

// After (required)
import { capture, identify } from "@wrelik/analytics/client";
import { captureError, initErrors } from "@wrelik/errors/client";
```

### For Mobile
Add environment variable for Sentry:
```
EXPO_PUBLIC_SENTRY_DSN=your-sentry-dsn
```

## Known Issues

1. Pull latest changes
2. Run `pnpm install` to get updated @wrelik/* packages
3. Rebuild with `pnpm build`
4. Deploy to Vercel
