# Deelrx CRM docs

Deelrx CRM is built for operators who need clear answers during live store hours.

Use this docs set to run DRX day to day. Every guide below maps to routes and labels that are live in the app as of March 4, 2026.

## What this docs set covers

- Shift-start setup and first-sale checks
- Standard Sales and Quick Sale workflows
- Inventory intake, adjustments, and audit trail habits
- Customer and credit workflows
- Team roles, session controls, and privacy controls
- Beta boundaries so teams do not depend on unfinished surfaces

## Notes for operators

- Use route labels in the app when following these guides: **Quick Sale**, **Sales**, **Inventory**, **Customers**, **Credit**, **Operations Insights**, **Reports**, **Settings**, and **Help Center**.
- If a guide says a surface is beta, treat it as limited and keep a manual fallback ready.
- If a page in the app does not match this docs set, report it through the in-app issue flow and include the route.
