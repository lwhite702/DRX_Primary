# Staying compliant

Deelrx CRM keeps an operational audit trail with controlled stock actions and documented reasons.

## What this does

- Logs stock changes in **Inventory Audit Log**
- Captures reasons on adjustments
- Supports shrinkage and personal-use logging
- Runs random inventory check workflows

## Why this matters

You need a clean record when totals do not match physical stock.

## Step-by-step

1. Use **Inventory Intake** for received stock.
2. Use **Inventory Adjustment** for count corrections.
3. Enter a clear reason every time.
4. Record shrinkage from the shrinkage flow when needed.
5. Review **Inventory Audit Log** regularly.

## Common mistakes

- Using vague reasons like "fix" or "update"
- Delaying shrinkage entries until end of week
- Skipping audit log review after shift disputes

## Edge cases

- Random check can flag discrepancies and auto-log outcomes.
- Supervisor PIN can be required for shrinkage flows depending on settings.

## Current limitations

- Compliance-specific export workflows are not surfaced as dedicated pages yet.
