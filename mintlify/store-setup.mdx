# Store setup

Deelrx CRM store setup combines onboarding and **Settings** so your operation data is correct from day one.

## What this does

- Configures business profile fields
- Sets tax behavior and POS manager PIN
- Controls unit defaults and store preferences

## Why this matters

Setup values drive receipts, tax totals, access behavior, and customer-facing details.

## Step-by-step

1. Complete onboarding fields for business and owner info.
2. Open **Settings** after onboarding.
3. Update **Business Profile** fields.
4. Configure tax and POS behavior in **Business Preferences** and **POS Security**.
5. Save and verify by running a test sale.

## Common mistakes

- Leaving tax rate blank when tax collection is enabled
- Setting a manager PIN and not documenting who can use it
- Skipping address/contact fields needed on receipts

## Edge cases

- Missing business profile blocks normal operation pages.
- Some settings actions require elevated role permissions.

## Current limitations

- Some setup defaults are opinionated and require manual post-setup tuning.
