This guide is the troubleshooting playbook for store staff when encountering register issues, card reader delays, or inventory discrepancies during active store hours.

## What this page is for

Use this guide when something isn't working as expected to quickly recover without double-charging customers or making messy data mistakes.

## Before you start

- **Recommended role**: Any staff member can run initial checks; supervisors or managers handle deeper account escalations.
- **Key screens**:
  - **Quick Sale** (`/pos/sale`) and **Sales** (`/sales`)
  - **Inventory** (`/inventory`)
  - **Customers** (`/customers`)
  - **Operations Insights** (`/insights`)
  - **Help Center** (`/help`): Submit a support request directly to our team.

## Fast path

1. **Pause and look at the screen**:
   - Note the exact screen name and what button was pressed.
2. **Tap once and wait**:
   - Avoid tapping submit buttons repeatedly if the screen takes a moment to respond.
3. **Check if the action already completed**:
   - If a payment screen lagged, check **Sales** to see if the receipt was generated before asking the customer to swipe again.
4. **Follow the common issue checks below**.
5. **Contact Support if unresolved**:
   - Email `support@deelrxcrm.com` or tap **Help** in the menu.

## If blocked

### 1. Checkout will not complete
- **Check**: Is the shopping cart empty? Was a payment method selected?
- **Store Credit**: If paying with store credit, is an active customer profile attached?
- **Out of stock**: Are any items in the cart showing 0 available stock?
- **Fix**: Select a payment method, attach customer if using credit, tap **Complete Order** once.

### 2. Barcode scanner does not find an item
- **Check**: Is the barcode smudged or poorly lit?
- **Fix**: Type the product name or SKU into search. Check in **Inventory** that the SKU is assigned to the product.

### 3. Customer profile will not save
- **Check**: Are there formatting errors in the optional phone number or email?
- **Fix**: Clear out the optional fields and save with just their first name or alias first, then add contact details later.

### 4. Daily sales numbers look lower than expected
- **Check**: Did you select the correct date filter? Are you in the right store workspace?
- **Fix**: Open **Operations Insights** (`/insights`) and ensure you are viewing today's date for your current store location.

### 5. "Permission Denied" message appears
- **Check**: Does the action require a Supervisor or Manager PIN (e.g., voiding an item or editing a tax rate)?
- **Fix**: Ask a shift supervisor or manager to enter their PIN or perform the action from their account.

## What to include when contacting support

When submitting a help ticket to `support@deelrxcrm.com`:

1. Which screen you were using (e.g. Quick Sale, Receive Stock).
2. What you were trying to do.
3. The exact message shown on the screen.
4. Whether the receipt or sale ID was created.
5. What device you were using (e.g., iPad Safari, iPhone, Android terminal, Desktop Chrome).
