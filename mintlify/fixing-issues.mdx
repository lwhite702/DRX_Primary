# Fixing issues

Deelrx CRM gives you a fast support path through **Help & Support**, **Report a Bug**, and in-app feedback actions.

## What this does

- Covers common operator issues
- Provides direct issue reporting from app UI
- Keeps support context tied to actual workflow pages

## Why this matters

Fast issue reporting reduces downtime during live operations.

## Step-by-step

1. Open **Help & Support**.
2. Check known issue patterns and fixes.
3. If unresolved, click **Report an Issue or Ask a Question**.
4. Include the exact page, action, and visible error text.
5. Re-test after applying the recommended fix.

## Common mistakes

- Sending "it broke" with no reproduction details
- Not including payment method or product context for sales issues
- Reporting inventory errors without product/SKU reference

## Edge cases

- Network interruptions can fail checkout while preserving cart state.
- Inventory and customer validation can block saves until required fields are fixed.

## Current limitations

- Dedicated support SLA/status tracking is not displayed in DRX app pages.
